# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | yes |

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub security advisories](https://github.com/itxshakil/laravel-form-shield/security/advisories/new),
or email itxshakil@gmail.com.

You'll get an acknowledgement within 72 hours. Please allow time for a fix before disclosing.

A way for a bot to reliably get past every check is a design discussion, not a vulnerability. Open a normal issue for those. Bypasses that compromise the app (token forgery, injection through stored signals, a denial of service via the inspector) are vulnerabilities.
